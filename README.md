# SilverQuant Professional

Next Generation of SilverQuant

SilverQuant 主打新手友好，为了不破坏现有用户的新手体验，同时实现新的性能架构方面的突破，在这里开一个新坑

基础环境安装
```
pip install -r requirements.txt -i https://pypi.tuna.tsinghua.edu.cn/simple/
```

Amazing 银河数智开发库安装
```
pip install ./_wheel/tgw-1.0.8.7-py3-none-any.whl
pip install ./_wheel/AmazingData-1.1.7-cp310-none-any.whl
```
